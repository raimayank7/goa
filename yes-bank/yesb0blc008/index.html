How the code YESB0BLC008 is built

YESB is the bank part: the letters of Yes Bank. The fifth character is always the digit 0. BLC008 is the part that names this branch.

The MICR code 403413008 is the number printed along the bottom of this branch's cheques. 403 is the city (the same three digits that begin the PIN code 403401), 413 is the bank and 008 is the branch.
